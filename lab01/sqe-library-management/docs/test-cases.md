# LibraryHub Test Cases

## 1. Test Case Overview

This document defines the 12 functional test cases required for the LibraryHub testing exercise. The test cases cover book registration, ISBN validation, book borrowing, book availability, book returning, member borrowing limits, and overdue fine calculation. The cases include positive, negative/error-path, boundary, and limit tests.

The test cases are derived from the LibraryHub functional requirements and are intended to be executed against the current Java implementation in the repository. Where a required operation is not available in the current implementation, the execution result will be recorded as **BLOCKED** during the manual execution phase rather than assuming an implementation exists.

## 3. Negative and Error-Path Test Coverage

The test suite contains more than the required three negative/error-path tests. The explicitly negative tests are:

* **TC-02:** Duplicate ISBN must be rejected.
* **TC-03:** Malformed ISBN must be rejected.
* **TC-05:** Borrowing with no available copies must be rejected.
* **TC-07:** Returning a book not borrowed by the member must be rejected.
* **TC-09:** Borrowing beyond the allowed member limit must be rejected.

Therefore, the suite contains **5 negative/error-path test cases**, exceeding the minimum requirement of 3.
